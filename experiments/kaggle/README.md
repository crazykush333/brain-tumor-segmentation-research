# Kaggle execution package (compute environment, not a dataset mirror)

These notebooks run the repository's gated CLI at an exact commit inside a **private Kaggle notebook session**. They are generated by `scripts/remote/make_kaggle_notebooks.py`; do not hand-edit the `.ipynb` files. The same steps run on a private VM ([`../vm/`](../vm/README.md)).

| Notebook | Job | Gate (checked in its first step) | Can run now? |
|---|---|---|---|
| `00_environment_probe` | probe and Aspera-client help; **no data** | none | **yes** |
| `01_data_access_and_b2` | JOB-01: official delivery, checksums, B2 import | `acquire_data` | yes, once the transfer route is confirmed in 00 |
| `02_grouping_and_split` | B7–B12 (B8 is human review) | `compute_t_screen` | no, needs B6 |
| `03_compute_pilot` | EXP-001 (D gates) | `run_exp001` | no, needs D1 (owner) |
| `04_training_job` | JOB-02..07: one resumable run | `train_main` | no, needs B12 and D1–D6 |
| `05_evaluation_job` | JOB-08 | `evaluate_internal_test` | no, needs the C gates and `eval-v1` |
| `06_results_export` | public-safe artifacts only | none | after results exist |
| `99_master_pipeline` | launcher of `scripts/remote/master_run.py`: the runner decides every next step | each step's own gates | yes (it stops at the first genuine blocker) |

Rules:

- Raw data stay in `WORK=/tmp/brats` and disappear with the session.
- Never save raw data as notebook output, never create a Kaggle Dataset with BraTS data, and never share session outputs that contain data.
- Only records, run manifests, reports, checkpoints and result artifacts go to `/kaggle/working`. The owner imports public-safe files with `export-artifacts` and moves gates in the owner's checkout.
- Enable GPU and Internet in the notebook settings.
- Never type credentials into a cell. If the repository is private, use a Kaggle Secret.
- Kaggle's session and quota limits are planning values (`configs/compute/remote_compute.yaml`). The probe measures hardware; quota is visible only in the account.
